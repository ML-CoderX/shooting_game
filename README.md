# NEON SIEGE

A Windows third-person arena shooter prototype built in Unity 6 / URP. Survive twelve escalating waves, build a stack of augments, and defeat Siege Wardens on waves five and ten.

## Play

Run `Builds/Windows/NeonSiege.exe` when the build is present. Keep the executable, `UnityPlayer.dll`, and `NeonSiege_Data` together.

For distribution, run `Tools/package-player.ps1` and share `Builds/NeonSiege-Windows.zip`. Extract the complete archive before playing.

| Action | Keyboard / mouse | Xbox controller |
| --- | --- | --- |
| Move / look | WASD / mouse | Left / right stick |
| Fire / aim | Left / right mouse | RT / LT |
| Sprint | Left Shift | Left stick press |
| Dash | Space | A |
| Reload | R | X |
| Next weapon | Q / mouse wheel | RB |
| Select weapon | 1–5 | Cycle with RB |
| Pause | Escape | Menu |
| Menus | Mouse | D-pad / A |

Dash grants brief invulnerability. Orange circles announce a boss strike: leave the circle before it detonates. Use cover against gunners and dodge their visible projectiles. Kills within four seconds build a score multiplier. Cyan supplies refill the magazine, pink supplies restore health, and orange supplies grant ten seconds of faster firing. Reloads have unlimited reserve ammunition.

Choose one of three augments between waves. Each cleared wave restores 15 health and refills the current magazine. Damage, rate, speed, health, dash and magazine upgrades stack; explosive rounds, lifesteal and ricochet are unique perks.

## Edit and build

- Open this project directory in **Unity 6000.6.5f1**, with Windows Standalone support. Dependencies are pinned in `Packages/manifest.json` and `packages-lock.json`.
- Open `Assets/_Project/Scenes/NeonSiege.unity` and press Play.
- The scene contains the baked arena and navigation data; runtime bootstrap creates pools, player, UI, and audio. Gameplay data is stored in `Assets/_Project/Resources` so runtime loading works in the standalone build.
- `Neon Siege → Rebuild baked arena` rebuilds the arena, navigation, light probes, and lightmaps. `Generate project` recreates only the bootstrap scene; rebuild the baked arena afterwards.
- Build through Unity Build Profiles for Windows, or run:

```powershell
powershell -ExecutionPolicy Bypass -File Tools/unity.ps1 -Method NeonSiege.Editor.ProjectBuilder.Build -Log build.log
```

The helper script currently points to the editor installed on this workstation. Adjust its editor path for another machine.

The arena uses URP Forward rendering with a single mixed directional light. Additional lights, light cookies and terrain/vegetation shader variants are disabled. Re-enable the relevant pipeline settings and update `ArenaShaderStripping.cs` before adding those features.

Commit `.gitignore`, `Assets` and their `.meta` files, `Packages`, `ProjectSettings`, `Tools`, and `Docs`. Unity caches, local editor state, logs, and generated `Builds` are ignored. Distribute the entire `Builds/Windows` folder to players.

## Extend

- **Weapons:** edit a `WeaponDefinition` under `Resources/Weapons`. Damage, fire rate, spread, recoil, magazine, pellets, range, reload, piercing and projectile mode are data fields. The current UI/input/presentation supports five slots; adding a sixth requires expanding those arrays and controls.
- **Enemies:** tune an `EnemyDefinition` under `Resources/Enemies`. New behaviors require an `EnemyKind`, implementation in `Enemy`, a matching definition and visual, and a spawn rule in `WaveDirector`.
- **Upgrades:** create an `UpgradeDefinition` with a title, description and effect. New effect types need an `UpgradeKind` and an `Apply` branch. Unique perks are excluded from later selections.
- **Waves:** edit `Resources/Waves/Run.asset` to change total waves, spawn counts, intervals, concurrent cap and boss frequency.
- **Art:** run Blender in background with `Tools/create_assets.py`, then run `NeonSiege.Editor.ArtBuilder.Create` in Unity. Source geometry uses meters, a shared 128×16 palette atlas, rigid skin weights, and FBX. The generator rebuilds all fifteen assets; `Tools/SiegeAssets.blend` is a sample source module.
- **Sound:** synthesized original SFX and an eight-second adaptive music loop are generated by `SiegeAudio` and routed through Master / SFX / Music groups in `Resources/Audio/Siege.mixer`.

## Saves and checks

Settings, input overrides, and high score live in `Application.persistentDataPath/profile.json` (normally `%USERPROFILE%\AppData\LocalLow\Siege Studio\NEON SIEGE`). Missing/corrupt profiles fall back to defaults. Saves are local only.

Validation evidence and limitations are recorded in `Docs/VALIDATION.md`. `Docs/full-run-validation.txt` records an accelerated progression test; it does not certify difficulty or normal run duration. `Docs/asset-stats.json` records exported mesh triangle counts.

Reproduce the editor progression check with `Tools/unity.ps1 -Method NeonSiege.Editor.RunValidation.FullRun -Log full-run.log -Play`. Launch the executable with `-siegeQA` for combat/input/save/asset checks, or `-siegePerf` for a 1080p, 24-enemy performance sample. These modes quit automatically and write reports beside the executable. Performance mode uses an invulnerable stationary operator and uncapped rendering; it is not a full-run benchmark.

`Tools/verify-player.ps1 -Mode QA -Show` runs the visible standalone checks and copies their report into `Docs`. Use `-Mode Perf` for the benchmark. The final recorded sample averaged 391.8 FPS, with 299 peak draw calls and 86,018 triangles; see the validation record for test conditions and limits.
